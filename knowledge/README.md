# Knowledge boundary

This directory is the version-controlled home for anonymized, reusable Agent knowledge. It establishes a stable boundary for later tickets without implementing their behavior.

- `rules/` holds versioned, cross-project rule snapshots. Rules must state version, provenance and applicability.
- `cases/` holds anonymized evidence and reusable case knowledge. Never copy real project conversations, screenshots, element IDs or geometry here.
- Project-specific corrections and live session knowledge belong under the ignored `AI_Area_Assistant_Data/` directory, not in Git.

Promoting project experience into these shared directories requires explicit user approval and a reviewed pull request.
