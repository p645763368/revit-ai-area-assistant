# Issue #6 Revit 2026人工测试说明

本测试只读取元素并改变Revit界面的临时选择/定位状态，不创建或修改模型元素，也不会自动保存。请只在开发测试副本中执行，不要打开原模型做测试。

## 测试前准备

1. 完全关闭Revit。
2. 确认pyRevit只加载本Issue worktree中的扩展：

   `revit-ai-area-assistant-issue-6\pyrevit\AI Area Assistant.extension`

3. 启动Revit 2026并打开指定开发测试副本。
4. 打开“AI Area Assistant”右侧面板，等待文档安全状态显示`bound / verified / allowed / none`。
5. 记录测试开始前的`IsModified`值。不要在测试过程中点击保存。

## 测试一：读取当前选择集并过滤类别

1. 在Revit视图中先选择一个Floor和一个Wall。
2. 如果方便，再按住`Ctrl`选择一个不支持的元素，例如Door或文字注释。
3. 在面板“边界来源选择”卡片点击“读取当前选择”。
4. 面板应只列出Floor和Wall；不支持的元素不应进入列表，并应显示“已忽略1个不支持类别的元素”。
5. 每个有效元素应显示：Element ID、UniqueId、类别、关联楼层、类型、包围盒尺寸。

通过标准：不支持类别没有被接受，且有效元素摘要与Revit属性一致。

## 测试二：交互式多选和安全取消

1. 点击“交互式选择”。
2. 在模型中依次选择Floor、Roof或Wall，点击Revit选项栏的“完成”。
3. 面板应显示所选元素数量和摘要。
4. 再次点击“交互式选择”，然后按`Esc`取消。
5. 面板应显示“已取消选择”，Revit保持可操作，上一次有效选择仍保留，可继续点击“定位高亮”。

通过标准：交互模式只允许Floor、Roof和Wall；取消不报错、不锁住Revit、不清空上一次有效选择。

## 测试三：定位高亮不产生模型成果

1. 在已有有效选择的情况下点击“定位高亮”。
2. Revit应把这些元素设为当前选择并缩放到可见范围。
3. 面板应显示“已定位N个”。
4. 检查文档的`IsModified`，应与测试开始前一致。
5. Revit撤销列表中不应出现由本功能创建的模型操作。

通过标准：元素可见且被临时选中，但没有Transaction、永久图元或文档修改。

## 测试四：交给Agent分析

1. 保留一个或多个有效来源元素。
2. 点击“交给Agent分析”。
3. 对话区应显示包含元素摘要的请求，Agent开始流式回复。
4. 回复可以分析或提出问题，但本Issue不应创建Area、Boundary、Tag或任何其他模型元素。

如果模型API未配置，可以把“请求已进入对话区且显示可重试连接错误”记录为界面路径通过，并把真实Agent回复列为未测试。

## 测试五：文档切换清除旧选择

1. 新建一个未保存空白项目，不要保存。
2. 切换到空白项目。
3. 文档安全状态应变为`paused / denied / document_changed`。
4. 边界来源选择应变为“未选择”，并提示需要重新选择。
5. “定位高亮”和“交给Agent分析”按钮应禁用，旧文档Element ID不能用于新文档。
6. 关闭空白项目时选择“不保存”。
